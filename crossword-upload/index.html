First time? Set up your upload key
  1. Open GitHub’s key setup and sign in as narasimharaokvn-dev.
  2. Name it Crossword Upload and choose an expiry date.
  3. Under Repository access, select Only select repositories, then KVN-Telugu-Crossword.
  4. Under repository permissions, give Contents: Read and write. Leave other permissions unchanged.
  5. Generate the key, keep it in your password manager, and paste it above. Do not send it to team members.
